# 📱 IPO Telegram 알림 봇

38커뮤니케이션에서 공모주 정보를 자동으로 수집하여 청약일과 상장일에 Telegram으로 알림을 보내주는 봇입니다.

## 🚀 기능

- ✅ 38커뮤니케이션에서 공모주 정보 자동 수집
- ✅ 청약일 오전 9시에 Telegram 알림
- ✅ 상장일 오전 8시 50분에 Telegram 알림
- ✅ 스팩(SPAC) 종목 자동 제외
- ✅ 중복 알림 방지

## 📋 설치 방법

### 1. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. Telegram Bot 생성

1. Telegram에서 [@BotFather](https://t.me/BotFather)를 검색
2. `/newbot` 명령어로 새 봇 생성
3. 봇 이름과 username 설정
4. 받은 **Bot Token** 저장

### 3. Chat ID 확인

1. [@userinfobot](https://t.me/userinfobot)에게 메시지 전송
2. 받은 **Chat ID** 저장

### 4. 환경 변수 설정

`.env.example` 파일을 `.env`로 복사하고 정보 입력:

```bash
cp .env.example .env
```

`.env` 파일 내용:
```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

## 🎯 사용 방법

### 프로그램 실행

```bash
python ipo_telegram.py
```

### 실행 시 동작

1. **즉시 실행**: 프로그램 시작 시 현재 청약일/상장일 체크
2. **자동 스케줄링**:
   - 매일 오전 8시 50분: 상장일 체크
   - 매일 오전 9시: 청약일 체크

### 백그라운드 실행 (Windows)

작업 스케줄러를 사용하여 자동 실행:

1. 작업 스케줄러 열기
2. "기본 작업 만들기" 선택
3. 트리거: 컴퓨터 시작 시
4. 동작: `python C:\ipo\ipo_telegram.py`

## 🛠️ 문제 해결

### Bot Token 오류
- BotFather에서 받은 토큰이 정확한지 확인
- `.env` 파일의 형식이 올바른지 확인

### Chat ID 오류
- @userinfobot에서 받은 ID가 정확한지 확인
- 봇에게 먼저 `/start` 메시지를 보냈는지 확인

### 알림이 오지 않을 때
- 오늘 청약일 또는 상장일인 공모주가 있는지 확인
- 프로그램이 실행 중인지 확인
- 로그 메시지를 확인하여 오류 확인

## 📝 참고사항

- 프로그램은 계속 실행되어야 스케줄링이 작동합니다
- 서버나 항상 켜져있는 컴퓨터에서 실행하는 것을 권장합니다
- 과거 날짜의 청약일/상장일은 알림을 보내지 않습니다
