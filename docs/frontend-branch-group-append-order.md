## 변경 내용
- 펼친 지점 그룹에서 추가 페이지가 로드될 때 새 강좌가 기존 목록 중간에 삽입되지 않도록 수정했다.
- 같은 검색 조건과 정렬 기준에서는 처음 관측된 강좌 순서를 보존한다.
- 이후 로드된 강좌 ID는 해당 지점 그룹의 뒤쪽에 append한다.
- 검색 조건, 지도 범위, 필터 조건이 바뀌면 그룹 순서 캐시를 초기화한다.
- 정렬 기준 또는 보기 모드가 바뀌면 해당 기준으로 새 순서를 다시 생성한다.
