# Frontend Map Marker Count UI

## 변경 목적

지도 마커에서 브랜드 약자는 제거하고, 마커 내부에는 강좌 수를 표시한다.
문화센터와 교육·체험은 같은 MoonCen 브랜드 체계 안에 있으므로 provider/category별 색상으로 구분하지 않고 민트/틸 계열로 통일한다.
마커 안의 숫자는 리스트 번호가 아니라 해당 지점의 강좌 수만 의미한다.

## 구현 내용

- `frontend2/src/components/CenterMapMarker.tsx`를 추가했다.
- 기본 마커는 흰색 배경, `#14B8A6` 테두리, `#0F766E` 텍스트를 사용한다.
- hover/selected 상태는 `#14B8A6` 배경, 흰색 숫자, `#0F766E` 테두리로 표시한다.
- 1000건 이상은 `999+`로 표시한다.
- 1~2자리 숫자는 14px, 3자리 이상은 12px로 표시한다.
- 모바일에서는 마커 크기를 38x46 기준으로 축소한다.
- 찜한 강좌가 있는 지점은 하트 배지를 표시한다.
- 마감임박 강좌가 있는 지점은 빨간 점으로만 표시한다.
- 강좌 수가 0인 지점은 지도에서 숨긴다.

## 데이터 기준

- 마커 숫자는 현재 화면의 필터를 통과한 `visibleItems` 기준으로 계산한다.
- 아직 강좌가 로드되지 않은 지점은 `active_course_count` 또는 `course_count`를 fallback으로 사용한다.
- 접수중 수는 `statusCode === OPEN` 또는 상태 텍스트의 접수중 값을 기준으로 계산한다.
- 마감임박 수는 `statusCode === DEADLINE` 또는 상태 텍스트의 마감임박 값을 기준으로 계산한다.
- 센터 단위 찜 모델이 없으므로, 해당 지점에 찜한 강좌가 하나라도 있으면 하트 배지를 표시한다.

## 팝업

마커 클릭 시 팝업에는 다음 정보를 표시한다.

- 문화센터명
- 브랜드명
- 강좌 수
- 현재 위치 기준 거리
- 마감임박 강좌 수
- 강좌 보기 버튼

## 유지한 동작

- 기존 Google Maps 라이브러리 구조는 유지했다.
- 기존 지도 클릭/지점 선택 이벤트는 유지했다.
- 기존 지도 필터 로직은 유지했다.
- 브랜드 정보는 마커 내부가 아니라 팝업에서만 표시한다.

## 2026-06-10 반경/색상 보정

- provider/category 색상 구분을 제거하고 MoonCen 민트/틸 계열로 통일했다.
- 마커 안의 숫자는 계속 강좌 수를 의미한다.
- 마감임박 상태만 빨간 점으로 표시한다.
- 브랜드/카테고리 구분은 마커 색상이 아니라 팝업, 리스트 텍스트, 카테고리 구성으로 표현한다.
- 지도 범례는 `숫자 = 강좌 수`, `♡ = 찜한 센터`, `● = 마감임박` 세 항목만 표시한다.
- 좌측 센터 리스트 hover/focus 상태는 지도 마커 highlight 상태와 연동한다.
- 반경 선택이 지도 viewport에 반영되도록 수정했다.
  - 5km: zoom 13
  - 10km: zoom 12
  - 20km: zoom 11
- 일반 모드의 고정 `minZoom: 13` 때문에 10km/20km 선택이 보이지 않던 문제를 수정했다.
  - 일반 모드 zoom range: `10..16`
- `branchCourseCounts`가 전달된 경우 지도 마커는 해당 결과 목록 count만 사용한다.
  - count가 없는 지점은 fallback count를 쓰지 않고 0개로 처리한다.
  - 문화센터/교육·체험 탭 변경 시 결과 목록에서 제외된 지점 마커도 함께 사라진다.
