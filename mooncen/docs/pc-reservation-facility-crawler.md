# Pyeongchang Reservation Facility Crawler

## Scope

- Provider: `MUNI_WWW_PC_GO_KR_B11A1ACA`
- Site: `https://reserve.pc.go.kr/pcreserve/reserve/sport`
- Parser: `pc_reservation_facility`
- Data type: public facility reservations, not course lectures.

## Source URL Correction

The original generated target pointed to a Pyeongchang county notice page:

```text
https://www.pc.go.kr/portal/government/government-news/government-news-agency?articleSeq=316071
```

That page is a lifelong education voucher notice and does not contain reservable course or facility rows.
The crawler now uses the Pyeongchang integrated reservation system:

```text
https://reserve.pc.go.kr/pcreserve/reserve/sport
```

## Collection Paths

The provider collects three reservation sections:

- `/pcreserve/reserve/sport`: public sports facilities
- `/pcreserve/reserve/culture`: culture facilities
- `/pcreserve/training/facility`: training facilities

Each list page uses `.public_wrap` cards. Detail pages are loaded by POSTing:

- `mode=view`
- `seq=<facility id>`

## Branch Handling

Some facilities appear in both the sports reservation and training facility sections.
To avoid duplicate map markers, branch identity is based on:

```text
facility title + normalized address
```

The course row remains section-specific, but the map branch is shared when the same facility appears in multiple sections.

## Notes

- The reservation system exposes operating hours, not event dates. `period` is set to `상시 운영`.
- Fee is available only when the detail page contains a fee table; culture facilities often do not expose a fee value.
- The visible detail page is generated by POST. `raw_url` stores a readable query-shaped reference, and `application_url` points to the section list page.
