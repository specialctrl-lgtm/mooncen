# 회원가입 개인정보 수집·이용 안내 계약

시행일: 2026-08-10  
문안 버전: `2026-08-10`

이 문서는 회원가입 화면과 서버가 함께 사용하는 필수 개인정보 수집·이용 안내의 검토된 기준을 기록합니다. 공개 개인정보처리방침 전체를 대신하지 않습니다.

## 안내 내용

| 구분 | 내용 |
| --- | --- |
| 제목 | 개인정보 수집·이용 안내 |
| 수집·이용 목적 | 회원 식별 및 로그인, 찜·내 강좌·알림 등 회원 기능 제공 |
| 수집 항목 | 이메일 주소, 이름(표시명), OAuth 제공자 식별자(소셜 가입 시), 비밀번호(암호화하여 저장, 이메일 가입 시) |
| 보유·이용 기간 | 회원 탈퇴 시까지. 다만 관계 법령에 따라 보존할 의무가 있는 경우 해당 기간 동안 보관합니다. |
| 동의 거부 및 불이익 | 동의를 거부할 수 있으나, 거부하면 회원가입 및 회원 기능을 이용할 수 없습니다. |
| 동의 표시 | [필수] 개인정보 수집·이용에 동의합니다. |

원본은 `config/privacy_membership_notice.json`입니다. JSON 객체를 UTF-8로 인코딩하기 전에 키를 정렬하고, 공백 없는 `,` 및 `:` 구분자를 사용하며, 유니코드 문자를 이스케이프하지 않은 canonical JSON의 SHA-256은 다음과 같습니다.

```text
4c01b656b92713aa35bf24149a12ce45e3e17f856d54beb950da4a69ad6e9000
```

## 저장 계약

- `privacy_notice_versions`는 안내 전문, 시행일, 법적 근거와 해시를 버전별로 보관합니다.
- `user_privacy_acceptances`는 신규 회원가입이 완료될 때 사용자가 동의한 버전과 가입 경로를 기록합니다.
- 가입 경로는 `email_signup`, `google_signup`, `naver_signup`만 허용합니다.
- 같은 사용자의 같은 안내 버전에는 하나의 `consent_granted` 기록만 허용합니다.
- 식별자와 동의 시각은 데이터베이스가 생성합니다.
- 기존 사용자 행에는 동의 기록을 소급 생성하지 않습니다. 기록이 없다는 사실을 동의로 간주하지 않습니다.
- 회원 탈퇴로 사용자가 삭제되면 연결된 동의 기록도 `ON DELETE CASCADE`로 삭제됩니다.

## 권한 계약

- `mooncen_api`는 안내 버전과 자신의 처리에 필요한 동의 기록을 조회할 수 있습니다.
- `mooncen_api`는 허용된 가입 필드로 동의 기록을 추가할 수 있지만, 안내 버전을 쓰거나 동의 기록을 수정·삭제·비울 수 없습니다.
- `accepted_at`과 `id`에는 애플리케이션 INSERT 권한을 부여하지 않아 서버 기본값을 우회할 수 없게 합니다.
- `mooncen_readonly`는 운영 점검을 위해 두 테이블을 조회할 수 있습니다.

## 운영 및 동기화

- 새 문안은 기존 버전을 수정하지 않고 새 버전 행과 새 마이그레이션으로 추가합니다.
- 운영 DB를 개발 DB로 동기화할 때 `public.user_*` 데이터 제외 규칙이 `user_privacy_acceptances`를 자동으로 제외합니다.
- 문안 원본인 `privacy_notice_versions`는 개인정보 행이 아니므로 개발 DB에 유지됩니다.
